> 目标：让「显示的针」和「传感器测出来的针」在同一个坐标系里对应上。

## 3. 变换链（核心公式）

### 3.1 静态：模型放在哪

```
T_A←M  ：模型文件 → 装配系（若从 CAD 直接导出，一般 = 单位阵）
```

模型必须**按 CAD 真实坐标摆放**，不能再"包围盒居中 + 缩放 170 mm"，否则针尖/针座位置全错。

### 3.2 动态：针怎么动

设备输出 `R_S←W(t)`（传感器 → 世界）。针轴在传感器系里的常量：

```
n_S = R_A←Sᵀ · u_A ,   u_A = (0,−1,0)
```

世界系里的针方向：

```
u_W(t) = R_S←W(t) · n_S
```

相对参考姿态 t0 的旋转（显示用）：

```
R_rel(t) = R_S←W(t) · R_S←W(t0)ᵀ            （世界系内的相对旋转）
```

把模型绕**针座**旋转（在装配系里表达）：

```
R_A_rel(t) = R_A←S · R_rel(t) · R_A←Sᵀ
v'(t)      = hub + R_A_rel(t) · (v − hub)     v 为模型顶点（A 系）
```

最后再做 A → D 的固定视图变换（或直接把 A 当成显示系，Z 向上即可）。

> 现在的代码做的是 `v' = R(DOWN→u) · (v − bbox_center)`，等于假设"模型沿 −Z、旋转中心在包围盒中心"，与你的 CAD（沿 −Y、中心在 hub）完全不符——这就是对不上的直接原因。

## 4. 为什么现在显示的针对不上（三条）

| # | 现在的做法 | 你的实际情况 | 后果 |

| 1 | 模型包围盒**居中**到原点 | 针座在 (0,195.25,9.56)，针尖在 Y≈−17 | 模型整体偏移，针座不在原点 |
| 2 | 强制旋转 `DOWN → 当前轴` | 模型针轴是 **−Y**，不是 −Z | 模型被转错 90°，且旋转中心错 |

## 7. 实施记录（2026-11-07）与一处修正

### 7.1 修正：针的露出方向是 +Y，不是 −Y

进一步核对几何（手柄零件 Y≈0…20，针芯 Y≈−17…195）后确认：

| 项 | 之前（按坐标系表推断） | 修正后（按几何） |
| --- | --- | --- |
| 针尖 | Y≈−16.95 | **Y≈194.73（+Y 端）** |
| 露出方向 | −Y | **+Y** |
| 旋转中心（针座） | (0,195.25,9.56) | **(0, 18.38, 9.56)**（针从手柄伸出处） |
| 露出针长 | 211.7 mm | **176.35 mm** |

依据：针芯从 −16.95 延伸到 194.73，而手柄只占 0…20；+Y 侧露出约 175 mm，
−Y 侧只有约 17 mm（针尾），因此插入方向是 +Y，针尖在 +Y 端，旋转中心在手柄前缘。

## 8. 2026-11-08 修正：四元数输入与「完整相对旋转」

第 7 节解决了**静态摆放**（模型按 CAD 坐标、针座为旋转中心），但动态映射还有两个问题。
本节的改动只做一件事：**让真实针的位姿变化与上位机模型的位姿变化一一对应**。

### 8.1 原来的三个问题

| # | 原做法 | 后果 |
| --- | --- | --- |
| 1 | 用 `roll/pitch/yaw` 现算四元数，设备发来的 0x59 四元数被丢掉 | 欧拉角在针接近竖直时有万向锁；设备内部融合结果也被二次解释 |
| 2 | 模型旋转用 `Quaternion.from_two_vectors(model_axis, axis)` | 只把「模型针轴」转到「当前针轴」，**绕针轴的滚转被丢掉** |
| 3 | 每帧重新做最短弧对齐 | 带手柄/PCB 的模型在滚针时乱转；倾角与滚转组合时姿态不唯一 |

对圆柱针"滚转无所谓"，但导入的是**带手柄的整支穿刺针**，滚转是可看见的自由度。
所以第 2 条不是精度问题，而是**位姿自由度不完整**。

### 8.2 新的变换链（已实现）

记号与第 1 节一致：`S` 传感器系、`W` 世界系、`M` 模型/CAD 系、`D` 显示系。

```
q_SW(t)   设备四元数：传感器 → 世界（Hamilton, w/x/y/z）
s         针轴在传感器系中的常量（hub → tip）
u_W(t)    = R(q_SW(t)) · s

相对世界旋转（与安装矩阵无关）：
R_rel(t)  = R(q_SW(t)) · R(q_SW(0))ᵀ

显示系（在参考姿态冻结）：
z_D       = −u_W(0)                    显示 +Z = 针的反方向
x_D       = 参考姿态下传感器 +X 在显示平面的投影
M_disp    = [x_D; y_D; z_D]            世界 → 显示

显示系中的相对旋转：
R_D_rel(t)= M_disp · R_rel(t) · M_dispᵀ     （参考时为 I）

模型的固定参考摆放（M → D）：
P_ref     = canonical_placement(model_axis, model_right)

最终模型位姿：
R_model(t)= R_D_rel(t) · P_ref
p_D(t)    = R_model(t) · (p_M − hub)
```

关键性质：

- **安装矩阵会在 `R_rel` 中自动抵消**，所以映射只需要一个常量：针轴 `s`。
  这也是"竖直法"只需一个姿态就能标定的原因。
- `R_D_rel` 保留了绕针轴的滚转：针滚 30°，模型手柄也滚 30°，而针轴方向不变。
- 参考姿态下模型的滚转角被规范化为"`model_right` → 屏幕 +X"。
  这个**常量**滚转不影响之后的相对运动；只有相对滚转有物理意义。

### 8.4 标定：一个竖直姿态就够

把针**竖直向下**放稳，点界面「标定针轴（竖直）」：

```
s = R(q_vertical)ᵀ · (0,0,−1)
```

只依赖重力，不需要磁力计、不需要知道朝向。结果会写入 `config/rig.json`，
并自动重新定参考。

如果方向相反（针尖/针尾反了），勾「针轴反向」或重新标定；
如果左右相反（往右倾、界面往左），把 `invert_quaternion` 设为 `true`
（表示设备四元数是世界→传感器），或把 `s` 的相应轴取反。

### 8.6 仍然对不上时的排查顺序

1. **方向整体反了**：`needle_axis_sensor` 取反（界面「针轴反向」）。
2. **左右/前后对调**：`s` 的轴选错了（例如实际是 +X，配置写 +Y）→ 重新竖直标定。
3. **左右镜像**：设备四元数约定是 world→sensor → `invert_quaternion=true`。
4. **只有滚转差一个常量**：这是显示系在参考姿态的规范化，**正常**；看相对变化即可。
5. **模型绕错中心**：`hub_mm` 不是针从手柄伸出的位置；CAD 模式下必须用真实坐标。
