# 穿刺针位姿引导系统 — 技术栈与技术路线

> 一句话：**IMU 负责"方向"，深度负责"距离"，标定负责"对齐"，GUI 负责"看清"。**
> 单靠这一颗 IMU，拿不到针尖的三维坐标——这是物理限制，不是实现问题。

---

## 0. 三个先决结论

1. **IMU 输出的是姿态，不是位置。** 9 轴融合给出的是三轴角度（3 自由度）；
   针尖位置必须由 `已知入点 + 针的方向 + 进针深度` 推算，深度必须有第二个来源。
2. **圆柱针只需要 2 个自由度。** 绕针轴的自转既测不准也没有临床意义，所以状态量是
   一个单位方向向量 `u`，不是完整姿态。顺带一个好处：**不要用欧拉角**——针竖直向下时
   pitch = ±90°，正好落在万向锁奇点上。
3. **用"相对参考姿态"，不要依赖磁北。** 开机/摆位时把当前姿态定为 0°，之后只看变化量。
   手术室的金属床、超声探头、电刀会持续破坏磁场，而相对姿态只依赖陀螺 + 加速度。

## 1. 传感器的能力边界

### 1.1 能测什么、不能测什么

| 量 | 能否从这颗 IMU 得到 | 说明 |
| --- | --- | --- |
| 俯仰 / 横滚（相对重力） | ✅ 可以，静态精度最好 | 加速度计提供绝对重力参考 |
| 航向 / 绕垂直轴转角 | ⚠️ 有条件 | 需要磁力计，且只在无磁干扰时可信 |
| 针轴方向（3D 单位向量） | ✅ 可以 | 上述两者的组合，用四元数表示 |
| 绕针轴自转 | ➖ 不需要 | 圆柱对称，测量它没有意义 |
| 三维位置 / 位移 | ❌ 不可以 | 见 1.2 |
| 速度 | ❌ 不可以 | 位置微分，同样发散 |

### 1.2 为什么不能"积分加速度求位置"

加速度计测的是比力：

```
a_meas = a_true + g + b + n
```

减去重力后还剩零偏 `b`（标定后仍有 mg 级残差）和噪声 `n`。两次积分后误差随时间平方增长：

```
位置误差 ≈ 0.5 · b · t²
```

| 零偏残差 | 2 s 后 | 5 s 后 | 10 s 后 |
| --- | --- | --- | --- |
| 1 mg (0.0098 m/s²) | 20 mm | 123 mm | 490 mm |
| 5 mg | 98 mm | 613 mm | 2452 mm |
| 10 mg | 196 mm | 1226 mm | 4903 mm |

**结论：没有外部基准（光学、电磁、机器人、超声）时，"IMU 直接给三维位置"不成立。**
任何声称能做到的方案，要么偷偷用了第二个传感器，要么在几秒内就失效。

### 1.3 那位置怎么办：运动学

```
p_tip = p_entry + d · u
```

- `p_entry`：入针点（可以在体表标记，也可以定义为"术区坐标系原点"）
- `u`：针的单位方向（IMU 提供，2 个自由度）
- `d`：已进针深度（第二个传感器或人工输入）

由此还能直接给出两个临床上最有用的数：

```
角度偏差   θ = angle(u, u_plan)
横向偏差   e = d · sin(θ)
```

后者就是"照现在这个方向扎下去，到目标深度会偏多少毫米"，比单纯显示角度直观得多。

## 2. 方案选择

| 方案 | 输出 | 额外硬件 | 典型精度 | 成本 | 建议 |
| --- | --- | --- | --- | --- | --- |
| **A. 纯角度引导** | 方向角、与计划路径的夹角 | 无 | 角度 0.5–2° | 最低 | **M1 先做**，能覆盖大部分"手稳不稳"的反馈 |
| **B. 角度 + 深度（运动学）** | 针尖三维坐标（相对入点） | 深度输入 | 150 mm 处 2–6 mm | 低 | **M2 主线**，本项目的目标形态 |
| **C. 双 IMU 弯曲感知** | 针尖 + 针体弯曲 | 第二个 IMU | 取决于基线 | 中 | 柔性针/细针才需要 |
| **D. 光学 / 电磁跟踪** | 完整 6DoF | 跟踪设备 | 0.2–1 mm | 高 | 只有要求亚毫米时才上 |

> 关键判断：如果目标只是"进针角度对不对"，方案 A 就够了；如果要说"针尖现在在哪"，
> 就绕不开方案 B 的深度输入。方案 C/D 属于另一个量级的投入。

```
│                               │                                 │

│                               │      u = R(q) · s               │
│                               │                                 │
│  深度输入 ────────────────────┼─► 运动学 p = p_entry + d·u       │
│  (手工/编码器/超声)            │                                 │

│                     PoseState（含质量标志：数据年龄/干扰/有效）    │
│                               │                                 │
│                     GUI 30 fps（最新值轮询 + 告警）                │
│                               │                                 │
│                     记录 / 回放（CSV + JSONL）                   │
└────────────────────────────────────────────────────────────────┘
```

### 线程与实时性

| 线程 | 频率 | 职责 | 约束 |
| --- | --- | --- | --- |
| SDK 采集线程 | 50–100 Hz | 收包、解析、零偏/零位应用 | 不做耗时操作 |
| 估计（在采集回调内） | 同上 | 四元数更新、坐标变换、运动学 | µs 级，纯数学 |
| GUI 线程 | 30 fps | 读最新 PoseState、绘制 | **绝不等待 BLE** |
| 记录线程（可选） | 事件驱动 | 写 CSV、事件日志 | 不阻塞前两者 |

延迟预算（需要实测）：BLE 20–50 ms + 处理 < 5 ms + 渲染 16 ms ≈ **50–80 ms**。
对"手持进针"够用；对机器人闭环不够。

## 5. 坐标系与数学

### 5.1 约定（已固化在 `src/wt901/pose.py`）

- 世界系：**Z 轴向上**，X/Y 水平，右手系；重力方向 `(0,0,-1)`
- 针体系：针沿本地 **+Z**
- `R`：4×4 里的旋转部分，**针体系 → 世界系**，3×3 行主序
- `q`：同一旋转的四元数表示（Hamilton）

### 5.2 核心公式

```
标定常量   s  ：针轴在【传感器系】中的单位向量（安装后不变）
当前姿态   R  ：传感器 → 世界（IMU 给出）
针的方向   u  = R · s
零位参考   R0 ：按下"设为参考"那一刻的姿态
相对方向   u_rel = (R0ᵀ · R) · s
针尖位置   p  = p_entry + d · u_rel
角度偏差   θ  = arccos(u_rel · u_plan)
横向偏差   e  = d · sin θ
```

**注意标定只需要一个向量 `s`，不需要完整的安装旋转矩阵。** 因为针是圆柱体，绕轴自转
不影响任何结论——这既简化了标定（一两个静态姿态就够），也消除了"安装角度没对准"这个误差源。

### 5.3 代码现状

`src/wt901/pose.py` 已实现并通过 19 个单元测试：

| 函数 | 用途 |
| --- | --- |
| `Quaternion` | 欧拉↔四元数↔矩阵，组合、逆、插值基础 |
| `needle_axis_in_sensor(poses)` | 两姿态标定出 `s`，并返回一致性误差 |
| `axis_world(R, s)` / `relative_axis(R0, R, s)` | 绝对/相对方向 |
| `tip_from_axis(entry, u, d)` | 运动学针尖 |
| `predicted_tip_error_mm(d, θ)` | 误差预算 |
| `elevation_azimuth_deg` / `deviation_deg` | 给 UI 的角度量 |

## 6. 姿态估计

### 6.1 三条路线

| 路线 | 做法 | 优点 | 缺点 | 采用阶段 |
| --- | --- | --- | --- | --- |
| 1 | 直接用设备输出的欧拉角 | 立刻能做，零开发 | 黑盒滤波；欧拉角有万向锁/绕回；航向可能混入磁 | **M1** |
| 2 | 自研 Madgwick（accel+gyro，磁可选） | 输出四元数、参数可控、可做磁干扰剔除 | 需调参、需验证 | **M2** |
| 3 | EKF + 外部观测（光学/超声） | 可融合位置，精度最高 | 工程量大 | 需要时 |

### 6.2 为什么内部一律用四元数

- 针可以竖直向下（pitch = ±90°），欧拉角在此处奇异；
- 设备角度会 ±180° 绕回，直接做差会跳变；
- 四元数平滑（slerp）让 30 fps 渲染平滑，且不积压旧帧。

欧拉角只在**显示**时计算，且只显示相对角度。

### 6.3 零偏与漂移

- 上电静止 3 s 做零偏标定（SDK 已有 `calibrate_gyro_bias`）；
- 残余零偏直接导致航向漂移，**必须实测**：静止 10 分钟，记录角度漂移率；
- 缓解手段：① 每次操作前"设为参考"；② 手术窗口控制在几分钟内；③ 需要更长时用磁力计
  或外部基准。

### 6.4 磁力计策略

默认**关闭**。若开启，必须做干扰检测：

- `|B|` 偏离当地地磁强度超过阈值 → 降级为 6 轴；
- 三轴变化率异常 → 判定为干扰；
- 降级时 UI 明确提示"航向不可信"，且**不要**悄悄切换（会造成姿态跳变）。

### 6.5 量程建议

当前默认 ±2000 dps，分辨率约 0.061 dps/LSB。穿刺针运动很慢，如果设备允许配置到 ±250 dps，
分辨率提升 8 倍，对积分漂移有实际好处。这一项在 M0 用厂商上位机确认是否可改。

## 7. 安装与标定（决定精度的一步）

### 7.1 机械安装（对应图片红圈位置）

- 位置：针座/hub 处（红圈），用**抱箍式** 3D 打印件（PA12 或 PETG），可快拆；
- 质心尽量靠近针轴，避免给细针附加弯矩；传感器+电池约 10–20 g，需实际评估手感；
- **必须防转**：针在夹持件里转动是"传感器看不见的错误"，会让所有角度整体偏一个常数。
  做法：针座铣一个平面/打一个定位销，或夹紧后用记号笔画线，术前目视确认；
- 传感器在无菌区外，套无菌袋；**不能高温高压灭菌**；电池与线缆要防牵拉；
- 不要遮挡活检枪的击发/上膛滑轨（图中右侧机构）。

### 7.2 针轴标定：两姿态法

只需要两个"已知世界方向"的静态姿态：

1. 针**竖直向下**，记录 `R1`，此时 `w1 = (0,0,-1)`；
2. 针**水平指向标记方向**，记录 `R2`，此时 `w2` 由标记给出（如 `(1,0,0)`）。

```
s_i = R_iᵀ · w_i        （针轴在传感器系中的观测）
s   = normalize(mean(s_i))
一致性 = max angle(s_i, s)   ← 应 < 1°，否则说明装夹滑动或方向假设错了
```

代码：`needle_axis_in_sensor([(R1,w1),(R2,w2)])`。

> 如果只有竖直一个姿态也能算 `s`，但绕轴分量不可约束、且无法做一致性检查；
> 建议至少两个姿态，且夹角 > 30°。

### 7.3 零位

按下"设为参考"记录 `R0`（也可用计划路径方向）。此后所有显示都是相对 `R0`。
这样即使磁北漂移、传感器开机方向不同，界面也始终一致。

### 7.4 深度标定

| 方式 | 精度 | 备注 |
| --- | --- | --- |
| 针身刻度人工读数 | ±2 mm | 最省事，UI 给输入框 + 步进按钮 |
| 线性编码器 / 拉线传感器 | ±0.1 mm | 需要一个进针导向夹具 |
| 超声图像 | 依赖分割 | 工程量大，但能同时给入点/目标 |

## 9. 精度预算

### 9.1 角度误差来源

| 来源 | 典型量级 | 说明 |
| --- | --- | --- |
| 陀螺零偏残差 | 0.1–1°/min | 短时影响小，需实测 |
| 加速度噪声 | 0.1–0.3° | 静态 |
| 装夹重复性 | 0.2–1° | 每次重新夹装都会变，需保证可重复 |
| 标定残差 | 0.2–0.5° | 两姿态法的极限 |
| 动态滞后 | 0.5–2° | 快速挥动时，滤波带来滞后 |

**合成预期：静态 0.5–1.5°，动态 1–3°**（以 M0 实测为准）。

### 9.2 角度 → 针尖横向误差

| 深度 \ 角度误差 | 0.5° | 1° | 2° | 3° |
| --- | --- | --- | --- | --- |
| 100 mm | 0.9 mm | 1.7 mm | 3.5 mm | 5.2 mm |
| 150 mm | 1.3 mm | 2.6 mm | 5.2 mm | 7.9 mm |
| 200 mm | 1.7 mm | 3.5 mm | 7.0 mm | 10.5 mm |

深度误差按 1:1 叠加。所以"150 mm 深、1° 误差 → 约 2.6 mm"是本系统的合理预期；
**要亚毫米，必须上外部跟踪**。

## 10. 失效模式与安全

| 失效 | 检测方式 | 处理 |
| --- | --- | --- |
| 蓝牙断链 / 数据停更 | `status.last_reading_age_s` > 200 ms | 立即置灰、隐藏针、显示 NO DATA；**不得保持上一姿态** |
| 磁干扰（若开磁） | \|B\| 偏离 / 变化率 | 降级 6 轴 + 明确提示 |
| 夹持滑移 | 标定一致性、术前目视 | 无法在线检测，只能靠机械防转 + 术前检查 |
| 深度输错 | 与刻度交叉核对 | UI 显示输入值并要求确认 |
| 传感器脱落 | 数据突变到不合物理 | 合理性检查 + 报警 |
| 电量低 | 设备电量/丢包率升高 | 提前告警 |

**安全原则**：这是"辅助引导"，不是"唯一引导"。任何显示都要能一键退回超声/解剖标志；
系统停机时必须是"看不见"而不是"停在上一帧"。

## 15. 需要你确认的四件事

1. **针是刚性还是柔性？** 活检针/粗针（图中这种）可当刚性；细针（神经阻滞、腰穿）会弯，
   需要方案 C。
2. **输出要"角度"还是"针尖坐标"？** 决定要不要做深度输入。
3. **深度怎么来？** 手工读数 / 编码器 / 超声。
4. **用途是临床还是样机？** 决定是否现在就走 62304 的流程。

回答这四个问题，我就可以把 M1 的界面和 M2 的深度接入直接排期实现。
