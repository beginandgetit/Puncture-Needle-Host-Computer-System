# 针尖旋转模式（tip pivot）

> 目标：同一套四元数跟踪下，提供两个旋转中心：
> **针座（hub）** 或 **针尖（tip）**。
> 只改变渲染时的平移基准，不改变姿态、针轴、偏差角。

---

## 1. 坐标变换

模型点在模型系 `M` 中为 `p_M`，跟踪器给出模型 → 显示系的旋转 `R_model`。
围绕模型系中的点 `pivot_M` 旋转，并把该点放到显示系原点：

```text
p_D = R_model · (p_M − pivot_M)
```

- **hub 模式**：`pivot_M = hub_mm`
  → 针座在显示原点，针体沿 `R_model · model_axis` 向下。
- **tip 模式**：`pivot_M = tip_mm = hub_mm + needle_length_mm · model_axis`
  → 针尖在显示原点，针体从原点向反方向延伸。

代码中的通用形式（`pose.rotate_about`）：

```text
p_D = anchor + R · (p_M − pivot_M)
```

`anchor` 默认是显示原点；如果以后要把针尖固定在某个靶点而不是原点，只需要传 `anchor`，
旋转矩阵和跟踪链路完全不用改。

---

## 2. 为什么不改旋转矩阵

四元数给出的是**姿态** `R_model`，与绕哪个点旋转无关。  
旋转中心只影响平移项：

```text
p_D = R_model · p_M − R_model · pivot_M
```

所以切换 hub/tip 时：

- `R_model` 不变；
- 针轴方向、倾角、φ/ψ、偏差角都不变；
- 只有模型在屏幕上的位置平移了 `R_model · (hub_M − tip_M)`。

这正是“旋转矩阵的坐标变换”部分：**先平移到枢轴，再旋转**。

---

## 3. 使用方式

界面右侧新增「旋转中心」下拉框：

| 选项 | 含义 |
| --- | --- |
| 针座 (hub) | 原有行为，模型绕针座旋转，针座在显示原点 |
| 针尖 (tip) | 模型绕针尖旋转，针尖在显示原点 |

选择会写入 `config/rig.json` 的 `pivot_mode`，下次启动保持。

针尖坐标由现有参数计算：

```text
tip_mm = hub_mm + model_axis × needle_length_mm
```

CAD 模型必须保证：

- `hub_mm` 是针从手柄伸出的位置；
- `needle_length_mm` 是露出针长（hub → tip）；
- `model_axis` 是模型坐标中的 hub → tip 方向。

非 CAD 的居中演示模型按 `-Z` 为针轴、包围盒两端自动取 hub/tip。

## 4. 验收

| 用例 | 预期 |
| --- | --- |
| hub 模式导入 CAD 模型 | 针座在原点，针尖向下，模型绕针座转 |
| 切到 tip 模式 | 针尖移到原点，针座在针尖上方约 `needle_length` 处 |
| tip 模式下倾斜 | 针尖坐标不动，模型绕针尖转；针轴/角度读数不变 |
| 切回 hub | 恢复原有画面，模型不残留平移 |
| 重启程序 | `pivot_mode` 保持上次选择 |

自动化覆盖：

- `tests/test_rig.py`：`tip_mm`、`pivot_mm`、配置读写、非法值回退；
- `tests/test_pose.py`：`rotate_about` 的枢轴/锚点变换；
- `tests/test_gui_smoke.py`：场景 hub/tip 切换、下拉框同步所有视图。

## 5. 边界

- tip 模式把**针尖放在显示原点**，因此切换瞬间模型会整体平移一个针长；这是坐标基准变化，
  不是姿态跳变。
- 针尖位置仍然只是“模型几何推算”，不是 IMU 测出来的空间位置；IMU 没有平移。
- 若 CAD 的针尖不在 `hub + model_axis × length`，请修正 `needle_length_mm` 或 `model_axis`，
  否则 tip 模式会绕错点。
